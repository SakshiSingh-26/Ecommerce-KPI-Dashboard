E-Commerce Performance Dashboard
📊 Excel Dashboard | Dynamic Slicers | KPI Cards | Retention Analysis

This project is a full end-to-end E-commerce performance dashboard built in Excel using real-world style data from a beauty brand. It includes revenue analysis, customer segmentation, category/product performance, and retention KPIs — designed for founders, marketers, and analysts who want quick insights.

🌟 Overview

This dashboard summarizes monthly performance for an E-commerce brand and helps answer key business questions like:
How much revenue did we make this month?
Which categories and products are performing best?
What is the repeat customer rate?
Are we gaining or losing customer momentum?
How are orders and revenue trending over time?

The dashboard uses:
✔ Pivot tables
✔ Slicers
✔ Timeline filters
✔ Dynamic KPI cards
✔ Clean, minimal visual styling

📌 Key Metrics (KPI Cards)

The dashboard highlights four crucial KPIs:

Net Revenue: ₹37,12,641

Total Orders: 3200

Average Order Value (AOV): ₹1,160.20

Repeat Customer Rate: 99%

These KPIs update dynamically based on filters and timeline selections.

🎯 Insights & Findings
Haircare & Skincare were the top revenue drivers.

Repeat customers contributed significantly, leading to a strong 99% repeat rate.
Orders and revenue show upward momentum, especially in the last month.
Top products show strong SKU concentration, indicating opportunities to diversify.
New customer acquisition was lower, suggesting a need for acquisition campaigns.
